## Versioning Policy

Version format:

```text
MAJOR.MINOR.PATCH
```

- PATCH: fixes, polish, small content or behavior changes, and small internal
  cleanup.
- MINOR: new features, new sections, meaningful workflow changes, and notable
  improvements.
- MAJOR: stable release milestones, breaking changes, major redesigns,
  incompatible data/API changes, or a new project generation.
- Before `1.0.0`, minor versions can represent larger project iterations while
  the project is still stabilizing.
